# 电子偏转特性实验示例

[查看 Word 实验报告](电子偏转特性_实验报告.docx) · [材料、核对与验证说明](说明文档.md) · [测量数据](代码/数据/measurements.csv)

报告使用三档加速电压下的横向电偏转、纵向电偏转及磁偏转数据，共 75 个观测值；磁偏转的六个未测格保留为空。随附原始数据照片、六张分析图、计算结果、组装代码和模板。原实验讲义不随此示例发布，其页码和采用依据见说明文档。

使用 Python 3.11 或更新版本，在本目录运行：

```bash
python -m pip install -r 代码/requirements.txt
python 代码/analysis.py
python 代码/generate_report.py --work-dir ./work --output ./reproduced/电子偏转特性_实验报告.docx
```

数值计算读取随附 CSV；组装程序使用随附模板、图片和结果，不需要 MinerU 服务或本机原始文件路径。`analysis.py` 会更新随附结果及分析图；`--output` 可另存报告，`--work-dir` 保存临时组装记录。原讲义页面如需用于后续核验，可通过 `--source-pages` 明确提供各图片路径。

已交付版本经 Word 渲染并逐页检查，共 16 页，含 141 个原生可编辑公式对象和 7 个图像对象。重新生成的文档仍需按实际渲染结果检查；程序输出的待核验状态不能替代人工复核。报告中的回归标准误不代表完整测量不确定度。
