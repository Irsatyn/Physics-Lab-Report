## 数据核对与符号映射

照片上方表一对应 `measurements.csv` 的组别X，位移单位mm、电压单位V，统一为横向偏转电压U的dx下标；中部表二对应Y，统一为dy下标；下方表三对应M，励磁电流统一为I的m下标，单位mA。加速电压统一为U的2下标。Word中均采用原生可编辑公式及结构化下标。

逐格复核保留了以下改正值：X轴800 V、D=8 mm采用格子下方最终改写的12.5 V；Y轴1000 V、D=4、8、12 mm采用划去旧值上方的5、10.5、16.3 V。用户明确确认Y轴1000 V、D=16 mm为21.3 V，Y轴800 V、D=16 mm为17 V。其余数值及正负号直接对照原照片。

磁偏转三行的D=−12、+12 mm共六个格子未填写，CSV保留空值，Word保留空栏，不插值、不据线性规律补填。每档使用−9、−6、−3、0、3、6、9 mm七个真实点，足以完成斜率估计。总计使用75个记录值：横向27个、纵向27个、磁偏转21个；零点也计入。

讲义及照片均未提供仪表量程、准确度等级、位置判读限和同点重复测量，故没有编造完整A/B类不确定度或仪器精度。报告中的斜率标准误和图5误差棒仅描述回归残差导致的斜率统计精度，不能替代完整合成测量不确定度。

装置名称以“电子束实验仪”统一表述。讲义第5页正文型号写DZS-D，面板图写DSZ-D，两处字母顺序不同，不擅自确认具体铭牌型号。板长、板间距、漂移距离和线圈常数均只保留理论符号，未编造几何参数或磁场标定。

MinerU公式OCR中有字母l与数字1混淆、L与l混用等情况。原理推导对照讲义原页重新核验，统一电场几何量l、L、d和磁场几何量lm、Lm。偏转正号采用照片实际读数约定；电子电量e代表电荷绝对值，不改变电子实际为负电的事实。

## 复现方法

本次使用Codex打包Python运行时；MATLAB未发现可执行入口，按仓库要求降级为实际执行Python绘图。Matplotlib及其所需依赖仅放本轮临时运行时，未修改全局Python环境。数值计算和绘图的交付源码均已执行成功，六张图为360 dpi数值绘图，不使用AI生成图。

在具有Python及下列依赖的环境中，进入 `代码/` 后运行：

```text
python -m pip install -r requirements.txt
python analysis.py
python generate_report.py --work-dir <临时工作目录> --output <另存报告.docx>
```

`analysis.py` 使用自身路径定位数据和图片目录；`generate_report.py` 使用随附模板与组装程序输出Word，省略 `--output` 时会覆盖随附报告。原讲义页面图片仅在明确传入 `--source-pages` 时加入核验清单，不依赖临时目录名称。复现不会重新提交MinerU，数据CSV已包含最终核对的测量值。`finalize_report.py` 为仓库原始检查器，真正完成当前版本的图像及页面核验后，才能填写复核记录；它不能自动证明科学正确或已经看过图。
