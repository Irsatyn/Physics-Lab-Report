# Word 组装输入

依赖：Python 3.10+、python-docx、lxml。绘图另外需要 NumPy、Matplotlib，MATLAB 模板需要支持 `arguments` 和 `exportgraphics` 的版本；旧版应改写专用脚本。

`build_report.py input.json output.docx [--draft] [--template template.docx]`

模板选择顺序为显式 `--template`、JSON 的 `template_file`、默认模板；前两项同时存在时必须指向同一文件，否则拒绝生成。实际使用的模板自动纳入组装指纹，无须靠调用者重复填写才能追踪。输出路径与任一声明输入或实际模板重合时拒绝写入，原始数据、结果、视觉来源、照片和图像均受保护。

图片路径相对 `input.json` 所在目录解析；输出路径相对调用目录解析。JSON 顶层：

- `experiment`：非空实验名称。
- `template_file`：自定义模板原始文件路径，相对 input.json 所在目录解析，纳入模板内容指纹、质量复核和复现交付；复杂模板生成流程见 custom-template.md。
- `questions_provided`：可选布尔值。确认用户资料和讲义均无题目、且未要求自拟时设为 false，允许 `sections["8"]` 为空并保留第八部分标题；不写“待补充”或“未提供思考题”到报告，后者由工具返回 `delivery_notes`，写入聊天/单独交付说明。省略或 true 时第八部分仍必需有完整回答，不能以 false 豁免已给题目的漏答。
- `sections`：键 `"1"` 到 `"8"`，值为内容块列表；第五部分照片由 `data_photos` 独立插入。
- `data_photos`：真实照片路径列表，可多张。
- `missing`：可选，用户资料中的缺项。完整输出遇到缺项时报错；`--draft` 时注明待补充。
- `visual_sources`：讲义/数据文件中需要当前模型识图复核的全部渲染页或局部图路径列表；先清点再填写，不能漏列资料图表。
- `data_files`：实际计算用到的 CSV/XLSX 等输入路径列表，用于追溯、版本核验及源码复现。
- `result_files`：计算结果 JSON 路径映射，例如 `{"fit": "plots/results.json"}`。

每个内容块只有一个类型键：

- `{"text": "段落内容"}`：多行会拆成多段。
- `{"emphasis": "需要强调的正文"}`：小四加粗，两端对齐，首行缩进两字符，不把全篇正文都改为强调。
- `{"heading": {"text": "1.1 数据处理方法", "level": 2}}`：分级标题，level 为整数 1–5。八个章节标题自动使用一级；章节内通常从二级开始。标题本身不算必需正文内容。一级小三、二级四号，三级起小四并依次使用加粗、斜体、加粗斜体；标题编号由调用者填写。
- `{"equation": 表达式}`：原生 Word 公式。
- `{"table": {"headers": ["物理量", "值"], "rows": [["U / V", "1.00"]]}}`。
- `{"figure": {"path": "plots/data_plot.png", "caption": "图1 电压随电流变化"}}`：不能放第五部分冒充照片。
- 生图 API 的 figure 必须另加 `"source": "imagegen"`；文件 dpi 及 Word 实际插入尺寸下有效 dpi 均至少 300，脚本会拒绝低分辨率生图。原始像素、逐点数值核验和工具调用由调用模型保留证据。

figure/table 均可提供 `caption`（中文图表标题，五号加粗居中）和 `note`（中文简短补充注释，小五加粗，无首行缩进）。图题置于图下、表题置于表上，note 紧跟对应图表之后；没有注释内容时省略，不编造。未填写标题时生成器提供中文编号标题，正式报告应填写具体物理含义。显式纯英文标题/注释会被拒绝；包含物理符号和单位的中文标题允许。脚本只检查中文字符存在，仍须模型核对语言、题注含义以及图内文字。

figure 可提供正有限数值 `width_inches`、`max_height_inches`，用于改善分页；宽度会按页面可用范围和高度上限缩小，始终保持原始像素比例，不自动放大超过页面。默认数据图高度上限 4.6 英寸，照片 5.5 英寸；逐页检查后可调整。图表段落无缩进，表格为居中的三线表；表内文字默认五号，表头加粗。默认正文两端对齐、小四、首行缩进两字符，个人信息居中、无下划线，仅保留班级、姓名、学号、座位号四项空白栏。生成器控制初始排版，不能自动证明每页不存在大块留白。

公式树支持标量、`seq`、`frac`、`sub`、`sup`、`subsup`、`sqrt`，未知操作报错：

```json
{"seq": ["R=", {"frac": ["U", "I"]}, "=", {"frac": ["1.00 V", "0.0100 A"]}, "=100 Ω"]}
```

```json
{"seq": [{"sub": ["u", "R"]}, "=", {"sqrt": {"seq": [{"sup": ["a", "2"]}, "+", {"sup": ["b", "2"]}]}}]}
```

标量节点适合短符号、运算符、数字、单位，不是 LaTeX 或线性公式解析器。例如 `"\\frac{U}{I}"`、`"x^2"` 只会生成文本，不要如此输入。上下标、分式必须使用对应树节点。脚本不会推导公式、计算代入值或校验单位，这些由调用者先完成。

复杂积分/矩阵支持 `{"equation": {"omml": "<m:oMath xmlns:m=\"http://schemas.openxmlformats.org/officeDocument/2006/math\">...</m:oMath>"}}`。这里的省略号必须替换为完整合法 OMML，只允许非空 `m:oMath` 根、数学和 Word 命名空间元素；禁止 DTD/实体和外部资源。原始 OMML 是完整公式块，不能嵌入 `seq` 等公式树。先由可靠转换器或生成代码构造，检查编辑性和结构，再渲染核验科学含义。

### 计算结果绑定

`result_files` 指向实际执行计算后保存的 JSON。正文、公式标量和表格单元格可使用 `{{result:fit.slope:.3f}}`，引用 fit 结果的 slope，保留三位小数；省略格式默认六位有效数字。支持嵌套对象字段，仅允许有限的数值标量，空值/布尔值/缺少字段/未解析占位符会报错。单位写在相应物理量旁，转换应在计算代码中完成，不让模板做暗含的单位换算。

```json
{"text": "拟合斜率 a={{result:fit.slope:.3f}} V/mA。"}
```

```json
{"equation": {"seq": ["a=", "{{result:fit.slope:.3f}}", " V/mA"]}}
```

上例只能在斜率实际单位为 V/mA 时使用；如果需要电阻 Ω，在计算代码中保存转换后的电阻，再引用对应字段。

报告审计返回公式/图像数量、分章节图像位置、图像 dpi、无效数学容器数、`assembly_manifest`、`missing`、`delivery_notes`、`status` 和 `layout_verified`。非草稿检查要求真实照片路径、第六部分公式/数据图/过程，以及第六至八部分有效内容（仅第八部分可按 `questions_provided: false` 豁免）；空字符串和空表格不能代替其他必选内容。

`assembled` 仅表示已组装，不能证明科学正确或排版合格；`layout_verified` 默认 false。组装时把输入、结果绑定后内容、使用文件版本及草稿状态的指纹写入 Word 元数据，以便发现旧结果或旧图片。交付前必须执行 [quality-record.md](quality-record.md) 的最终检查。旧版本无组装记录的文档应重新生成，不手动补指纹绕过检查。

默认模板仅作为结构/样式参考。脚本保留其页面设置及样式，重建正文并清除示例绘图及旧个人信息占位。它不适用于要求逐项保留文本框、复杂表格或内容控件的其他模板；这种情况按 [custom-template.md](custom-template.md) 使用专用生成脚本处理模板副本，不能直接用 `--template` 重建正文。


## 行内公式与说明文档

所有普通文本字段（含标题、表格、图表题注）中，生成器将西文字母/希腊字母转换为行内 OMML，并将所有 Unicode 标点分成独立宋体字段。自动转换只改变对象类型，不推断变量下标或科学含义。参数、复合公式和单位请显式使用 `{{math:表达式JSON}}`；例如 `电流 {{math:{"sub":["I","m"]}}} 的测量值为 {{math:"1.20 mA"}}。`。此语法沿用公式树，支持分式/上下标/根号，直接嵌入当前段落。独立公式仍使用 equation；行内公式不计入各章节独立公式数量，避免掩盖独立计算公式缺失。

顶层 `explanation_notes: ["资料来源及符号映射……", "存疑项及确认状态……"]` 仅进入工具返回的 delivery_notes，生成器不写进正文；调用模型须把这些实际记录写入说明文档。不得把记录此字段误称为说明文档已经生成。正文 text、图表 note 只放科学内容，不放识读/生成/适用性/存疑声明。草稿提示不写正文，状态及缺项随返回结果写说明文档并使用草稿文件名。
